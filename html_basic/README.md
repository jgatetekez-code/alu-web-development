HTML Basic

A small personal website built from scratch with plain HTML, as part of learning the fundamentals of how web pages are structured and rendered by browsers.

 What this is about

This project starts with the simplest possible valid HTML page and builds it up step by step into a two-page site with a homepage and a tweets page — both sharing the same header/footer layout and validated against W3C standards. The goal was to really understand what's going on under the hood: DOCTYPE, the DOM, elements, attributes, and how a browser turns markup into a page.

 Rules I stuck to

- No frameworks or libraries — just raw HTML/CSS/JS
- Every file validates cleanly on the W3C Validator
- Every file ends with a newline

 Files

- html_basic/base_index.html` — the bare minimum valid HTML page
- html_basic/index.html` — the homepage
- html_basic/tweets.html` — a page with an embedded tweet
