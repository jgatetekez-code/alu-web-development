# CSS Basic

This project is part of my web development learning journey at ALU.

## Description

In this project, I practiced using CSS to style and organize a website. I worked with Flexbox to create the page layout and added responsive design so the website can work better on smaller screens.

## Files

- `css_basic/index.html` - Main webpage
- `css_basic/tweets.html` - Tweets webpage
- `css_basic/base.css` - Basic styling provided for the project
- `css_basic/styles.css` - My CSS styling and Flexbox layout

## What I Learned

- How CSS works with HTML
- How to use CSS selectors
- How to use Flexbox
- How to create a responsive webpage
- How to style text, backgrounds, and links
- How to use Git and GitHub to save and share my work
